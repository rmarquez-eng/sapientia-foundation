Notes:
- Set every record to "DNS only" (grey cloud) first so GitHub can issue the
  TLS certificate. After the repo's Pages settings show "Enforce HTTPS" as
  available/green (a few minutes to ~1 hour), you may switch to Proxied
  (orange cloud) if you want Cloudflare in front.
- Remove any existing A / AAAA / CNAME records on "@" and "www" that point
  somewhere else first.
- Repo Pages settings: https://github.com/rmarquez-eng/sapientia-foundation/settings/pages
